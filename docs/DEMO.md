# Guía rápida — Demo VISIONYX (10 minutos)

**Marca:** VISIONYX · *Inteligencia que conecta el mundo real*  
**Entorno:** demostración aislada (datos de ejemplo). No mueve torniquetes reales ni envía WhatsApp/Wompi/DIAN.

## Acceso

1. Abre el enlace de demo que te compartieron.
2. Inicia sesión con el usuario y la clave del archivo de credenciales (pide el archivo a quien te envió la demo).
3. Verás la franja ámbar **«Entorno de demostración»**.

## Recorrido sugerido (10 min)

| Min | Pantalla | Qué probar |
|----:|----------|------------|
| 0–1 | Login | Entrar y ver el logo VISIONYX |
| 1–2 | Inicio | Resumen del día, accesos y caja (datos ficticios) |
| 2–4 | Socios | Buscar, abrir una ficha, ver membresía |
| 4–5 | Membresías / Planes | Revisar planes Mensual / Trimestral / Anual |
| 5–6 | Rutinas y ejercicios | Ver una rutina asignada |
| 6–7 | Caja / Ventas | Recorrer ventas de ejemplo del retail |
| 7–8 | Torniquetes | Estado del controlador demo; **Probar acceso** simula la apertura |
| 8–9 | Sedes | Cambiar entre Norte / Centro / Sur (selector arriba) |
| 9–10 | Cuenta | Ver que es un entorno de prueba |

## Qué está simulado a propósito

- Apertura de torniquete / pulso eléctrico  
- WhatsApp (Evolution)  
- Cobros Wompi y facturación DIAN  

Todo lo demás del panel (socios, planes, rutinas, reportes, multi-sede) usa datos de ejemplo realistas.

## Si quieren verlo en vivo

Cuando la demo les convenza, agendamos una reunión corta para probarlo con su sede, su cámara y su torniquete en tiempo real.

## Reset del demo

El administrador puede regenerar los datos de ejemplo (seed) sin tocar la operación real. Los datos de demostración viven en una carpeta aparte (`data-demo`).
